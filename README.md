# Рубежный контроль №1 по ПиК ЯП

Вариант запросов **Г**, номер предметной области **2 — «Школьник — Класс»**.

## Состав проекта

- [`main.py`](main.py) — программа на Python.
- [`report_G_2.pdf`](report_G_2.pdf) — отчёт с постановкой задачи, полным кодом и результатами выполнения.
- [`results.txt`](results.txt) — вывод программы на тестовых данных.

## Запуск

Требуется Python 3.6 или новее. Дополнительные библиотеки не нужны.
Программа проверена на Python 3.13.0.

```bash
python main.py
```

## Реализованные запросы

1. **Г1, один ко многим:** классы, названия которых начинаются с буквы «А», и списки их школьников.
2. **Г2, один ко многим:** максимальный возраст школьников в каждом классе; сортировка по убыванию возраста.
3. **Г3, многие ко многим:** все связанные пары «школьник — класс», отсортированные по названию класса.

Количественный признак — возраст школьника. Связь один ко многим задаётся полем `Pupil.class_id`, а многие ко многим — объектами `PupilClass`.

Тестовые данные содержат три класса, пять школьников и семь связей многие ко многим. Названия классов условные; в модели многие ко многим школьник может посещать несколько учебных групп. Классы без школьников не включаются в результат Г2, поскольку максимальный возраст для них не определён.
